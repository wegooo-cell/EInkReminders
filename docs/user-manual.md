# 墨水屏提醒事项 · 使用说明书

适用版本：Mac App 1.0.1 / ZECTRIX NOTE4 黑白版固件 1.0.1
适用系统：macOS 13 或更新版本、iPhone/iPad 的 Apple“提醒事项”

## 1. 先理解系统怎样工作

这套程序由三个部分组成：

```text
iPhone / iPad / Mac 的 Apple 提醒事项
                 ⇅ iCloud
       Mac 上的“墨水屏提醒事项”应用
                 ⇅ 家庭局域网
          ZECTRIX NOTE4 黑白版
```

必须注意：NOTE4 不会直接登录 iCloud，也不会直接访问 Apple“提醒事项”。Mac 应用是中间的同步桥梁。

- 在 iPhone 或 Mac 新增事项后，iCloud 先把它同步到 Mac，Mac 应用再把它发送到墨水屏。
- Mac 关机、休眠、没有运行同步应用或不在同一局域网时，双向同步会暂停，但设备端尚未上传的操作会继续保存在 Flash 中。

## 2. 当前版本能做什么

- 显示所选 Apple 提醒事项列表中的未完成事项。
- 从 iPhone、iPad 或 Mac 的 Apple“提醒事项”新增事项并显示到墨水屏。
- 从手机浏览器打开 NOTE4 的局域网页，进行设备设置。
- 上键选择上一项，下键选择下一项，OK 键确认完成当前事项。
- NOTE4 可在设置中切换“今天、计划、全部、完成”四个视图。
- Mac 或 iPhone 的提醒事项经 iCloud 到达 Mac 后，Mac 应用会立即同步当前视图；30 秒、1 分钟、10 分钟、30 分钟或 1 小时的周期同步继续作为断线补偿，也可以手动点击“立即同步”。

当前版本暂不支持：

- 直接在墨水屏设备上新增事项；请在 iPhone、iPad 或 Mac 的 Apple“提醒事项”中创建。
- 将 Apple“提醒事项”中的删除操作同步到设备。
- NOTE4 脱离 Mac 后直接连接 iCloud。
- NOTE4 单页最多显示 6 项，可继续滚动浏览更多事项。

## 3. 第一次安装

### 3.1 浏览器刷入固件

1. 在电脑上使用 Chrome 或 Edge 打开 NOTE4 中文刷机页：`https://wegooo-cell.github.io/EInkReminders/`。
2. 用能够传输数据的 USB 线连接 NOTE4。
3. 点击“连接 NOTE4 并刷入”。
4. 在浏览器弹出的串口列表中选择 NOTE4 对应的 USB 串口。
5. 第一次安装建议选择清除设备数据后安装。
6. 等待写入和校验完成，中途不要拔 USB。
7. 安装完成后，拔掉 USB 再重新插入并正常开机。

如果浏览器一直连接失败：

1. 拔掉 USB。
2. 按照 NOTE4 的下载模式操作进入刷机状态。
3. 重新插入 USB，在网页中再次点击连接并选择串口。

### 3.2 给 NOTE4 配置 Wi‑Fi

1. 刷机重启后，NOTE4 会建立 `EInk-Note4-XXXX` 热点，并在屏幕显示配网二维码。
2. 用 iPhone 相机扫描二维码，点击提示加入设备热点。
3. 中文配网页面通常会自动弹出；未弹出时，在 Safari 访问 `http://192.168.4.1`。
4. 从页面列出的附近网络中选择家庭 2.4 GHz Wi-Fi，需要时输入密码，点击“连接此 Wi-Fi”。
5. 固件先验证连接，成功后才保存密码；失败时留在配网模式，可以直接修改并重试。
6. 成功后记录手机和 NOTE4 上显示的局域网 IP，设备随后自动重启。

以后更换到新环境且原 Wi‑Fi 无法连接时，可长按上键进入设置，先选择“重连 Wi-Fi”；只有需要更换网络时才选择“重新配网”。重新配网后连接 `EInk-Note4-XXXX` 热点并访问 `192.168.4.1`。

### 3.3 打开 Mac 同步应用

当前构建的应用位于：

```text
macOS/build/墨水屏提醒事项.app
```

1. 双击打开“墨水屏提醒事项”。
2. 如果 macOS 阻止首次打开：
   - macOS 14 及更早版本：在 Finder 中右键应用，选择“打开”，再确认一次。
   - macOS 15 及更高版本：先尝试打开一次应用，再到“系统设置 → 隐私与安全性”点击“仍要打开”。
3. 系统询问“提醒事项”权限时选择允许完全访问。
4. 系统询问“本地网络”权限时选择允许。
5. 在“设备地址”中输入屏幕刚才显示的地址，例如 `http://192.168.1.42`。
6. 在“提醒事项列表”中选择需要显示的列表，例如“提醒事项”或“工作”。
7. 开启“自动同步”，并选择需要的同步周期。
8. 点击“立即同步”。
9. 状态栏显示“已同步 X 项并刷新屏幕”即表示连接成功。

Mac 重新启动后，需要再次打开这个应用。当前版本尚未自动设置“登录时启动”。

## 4. 方法一：从 iPhone 添加提醒事项

1. 确认 iPhone 与 Mac 登录同一个 Apple 账户，并且都已开启 iCloud“提醒事项”。
2. 打开 iPhone 的“提醒事项”App。
3. 进入 Mac 同步应用中选定的同一个列表。不要添加到“在我的 iPhone 上”等只保存在本机的列表。
4. 点击“新提醒事项”。
5. 输入标题，例如“购买咖啡豆”。
6. 如有需要，设置日期、时间、备注或优先级。
7. 点击完成。
8. 等待 iCloud 把内容同步到 Mac。
9. 保持 Mac 上的“墨水屏提醒事项”应用运行。应用会按照所选周期同步；Apple 提醒事项发生变化后，会立即同步。
10. 想立即显示时，在 Mac 应用里点击“立即同步”。

成功后：

- 新事项会出现在 Mac 应用的“墨水屏预览”。
- 墨水屏刷新画面：
  - 变化范围较小时，使用局部刷新。
  - 变化范围较大，或已累计 8 次局部刷新时，使用全屏刷新。
- 设置了具体小时和分钟的事项，右侧显示 `HH:mm`，例如 `09:30`。
- 只设置日期、没有具体时间的事项，右侧显示“今天”。
- 日期和时间都没有设置的事项，也默认作为今天的待办，右侧显示“今天”。
- 明天或更晚的事项不会进入“今天”视图；在“计划”或“全部”中会显示“明天 11:00”或具体日期。
- 同一页同时出现多个时段时，列表自动插入“上午”“下午”“今晚”分组。

## 5. 方法二：从 Mac 添加提醒事项

1. 打开 macOS 的 Apple“提醒事项”App。
2. 进入 Mac 同步应用中选定的列表。
3. 新增事项并设置标题、日期、时间等信息。
4. 回到“墨水屏提醒事项”同步应用，点击“立即同步”，或等待自动同步。

后续行为与从 iPhone 添加完全相同。

## 6. 屏幕上的显示顺序

Mac 应用根据 NOTE4 当前视图获取所选列表的数据，然后按以下规则排序和筛选：

1. 有到期时间的事项排在没有到期时间的事项前面。
2. 有到期时间的事项按日期和时间从早到晚排列。
3. 到期时间相同时，按标题排列。
4. 没有到期时间的事项按标题排列。

四个视图分别遵循以下规则：

- 今天：显示无日期、已逾期以及日期为今天的未完成事项；当天有具体时间的事项可按上午、下午、今晚分段。
- 计划：显示所有设置了日期的未完成事项，按日期时间排列，不套用“今天”的时段过滤。
- 全部：显示所选列表中的全部未完成事项；今天、明天和以后日期的事项都会保留，并按日期时间排列。
- 完成：显示所选列表中的已完成事项，最近变动的事项排在前面。

空视图文案：只有“今天”视图在当天事项都已于今天完成时显示“都忙完了玩去吧”；如果今天本来没有事项，则显示“目前没有事项”。“计划”“全部”“完成”视图没有可显示事项时，一律显示“目前没有事项”。

NOTE4 的今天、计划和全部视图每页显示最多 5 项；完成视图没有时段标题，每页最多显示 6 项。可以用上、下键继续滚动：今天、计划和完成视图最多同步并浏览 20 项；全部视图同步当前列表里的全部未完成事项，不设置应用层项目上限。跨过当前可见窗口时，Mac 会按需发送下一幅画面。

标题在屏幕上最多显示约 16 个中文字符，超出部分会变成省略号；Apple“提醒事项”中仍保留完整标题。

## 7. 列表界面

NOTE4 页头显示当前视图名称；每行保留圆形状态标记、提醒事项标题和右侧的日期或具体时间。为了保证黑白屏文字清晰，Mac 会在生成 NOTE4 画面时省略事项标题中的 Emoji，但 Apple“提醒事项”里的原始标题不会被修改。Mac 同步窗口右侧会显示与设备相同的黑白预览。

NOTE4 长按上键进入设置，选择“切换视图”，再用上、下键选择并按 OK 进入：

- 今天：无日期、已逾期或日期为今天的未完成事项。
- 计划：所有设置了日期的未完成事项。
- 全部：所选列表中的全部未完成事项。
- 完成：所选列表中的已完成事项；此视图内 OK 不会重复执行完成操作。

切换后设备立即请求 Mac 同步。选择会保存在 NOTE4 中，设备重启后仍会保留。

新视图首次出现时不显示点状选中背景。第一次短按上键、下键或 OK 只显示第一项的选中背景，不会移动或完成事项；之后按键才执行正常操作。连续 30 秒没有按键时，选中背景自动隐藏。

NOTE4 对移动选中项、显示或隐藏选中背景等小范围变化使用局部刷新；累计 8 次局部刷新后自动执行一次全屏刷新以控制残影。切换整个视图或画面变化范围较大时仍会全屏刷新。Mac 只读取当前视图，不再为了更新四个计数同时读取完成和未完成事项；每次只发送当前选择画面及一张确认预览。

当事项是在 Mac 或 iPhone 上完成时，下一次同步刷新会直接把它从墨水屏移除。

只有从 NOTE4 按 OK 确认的事项，才会先显示一次完成状态：原来的空心圆内增加一个实心圆，标题加删除线，并紧跟在所有当前可见待办的下一行，而不是固定放在屏幕最后一行。它不能再被选中；约 5 秒后同步刷新并从屏幕移除。可连续确认多项，设备会分别保存并同步操作。

“今天”视图中的具体时间按以下时段划分：

- `00:00–11:59`：上午
- `12:00–17:59`：下午
- `18:00–23:59`：今晚

当“今天”视图当前五项待办横跨时段时，屏幕按时段分组显示。“计划”和“全部”不使用当天时段分组，明天的事项会显示为“明天 11:00”，更晚的事项显示具体日期与时间。

## 8. 使用 NOTE4 按键

- 上键：选择上一项；到达第一项后继续按会循环到最后一项。
- 下键：选择下一项；到达最后一项后继续按会循环到第一项。
- OK：确认当前事项完成。设备立即显示实心圆和删除线，并把操作保存到本地，随后同步到 Mac。
- 长按上键：进入设置页面。

刚进入视图时不会显示选中图案。第一次按上键、下键或 OK 只会显示选中项；继续操作才会移动或完成。长时间没有按键时，选中图案会自动消失。

## 9. 每日正常使用流程

推荐保持以下状态：

1. NOTE4 接通电源并连接家庭 Wi‑Fi。
2. Mac 与 NOTE4 位于同一局域网。
3. Mac 上保持“墨水屏提醒事项”运行。
4. 开启“自动同步”，并选择同步周期。
5. iPhone 和 Mac 使用同一个 iCloud 提醒事项账户。

之后可以正常在 iPhone 或 Mac 添加、修改、完成事项。变更经 iCloud 到达 Mac 后会自动触发同步，无需等待所选周期；定时同步仍会在通知遗漏或网络短暂中断时补偿。

## 10. 常见问题

### 新增后墨水屏没有变化

依次检查：

1. 新事项是否添加到了 Mac 应用选中的列表。
2. iPhone 和 Mac 的 iCloud“提醒事项”是否已经同步。
3. Mac 同步应用是否仍在运行。
4. “自动同步”是否开启，以及同步周期是否符合预期。
5. 点击“立即同步”，观察底部状态文字。
6. Mac 和 NOTE4 是否在同一局域网。
7. “设备地址”是否仍是 NOTE4 当前 IP。

### Mac 显示“同步失败”或 HTTP 错误

- 在 Mac 浏览器访问 `http://设备IP/api/status`。
- 能看到 JSON 状态说明网络和设备网页正常。
- 打不开时，检查设备供电、IP、路由器访客网络或 AP 隔离设置。
- NOTE4 的 IP 可能被路由器重新分配；可以在路由器设备列表中查找，也可以在设备设置中选择“重连 Wi-Fi”。

### 看不到“提醒事项”列表或权限被拒绝

打开：

```text
系统设置 → 隐私与安全性 → 提醒事项
```

允许“墨水屏提醒事项”访问。如果之前更换了本地签名版本，可能需要关闭后重新授权。

### 墨水屏长时间没有立即变化

NOTE4 的选中移动采用局部刷新，累计一定次数后自动执行全屏刷新以清除残影。切换视图、同步大范围内容或进入设置时可能执行全刷，这是黑白墨水屏的正常现象。

## 11. 数据与安全说明

- Apple 提醒事项内容由 Mac 通过系统 EventKit 权限读取。
- NOTE4 与 Mac 使用家庭局域网 HTTP 通信，当前原型没有配对密码或 HMAC 签名。
- 不要在路由器上把 NOTE4 的 80 端口映射到公网。
- 建议只在可信家庭网络中使用。
- 当前程序不会主动传播删除操作，以降低原型阶段误删提醒事项的风险。

## 12. 最短操作速查

### 从 iPhone 新增

```text
iPhone 提醒事项 → 进入指定列表 → 新增
→ 等待自动同步或在 Mac 点“立即同步”
→ 墨水屏刷新
```

### 完成事项

```text
上/下键选择事项
→ OK 确认完成
→ 等待 Mac 同步
→ Apple 提醒事项标记完成并刷新墨水屏
```
