# ZECTRIX NOTE4 使用说明

## 固件与硬件

此目录中的 `firmware-note4` 基于 ZECTRIX NOTE4 官方 MIT 开源示例移植，仅适用于
4.2 英寸 400 × 300 黑白 NOTE4，不适用于 NOTE4C。烧录会覆盖设备原固件。

构建要求 ESP-IDF 5.4 或更高版本：

```bash
cd firmware-note4
idf.py set-target esp32s3
idf.py build
idf.py -p /dev/cu.usbmodemXXXX flash monitor
```

## 首次配网

1. 启动 NOTE4；只有未保存 Wi-Fi，或在设备设置或手机控制页中选择“重新配网”后，
   设备才会建立 `EInk-Note4-XXXX` 热点，并在墨水屏显示动态 Wi-Fi 二维码。
2. 用 iPhone 相机扫描二维码，点击系统提示加入设备热点。
3. iPhone 通常会自动打开中文配网页面；如果没有弹出，访问 `http://192.168.4.1`。
4. 页面自动扫描附近网络。从列表选择家庭 2.4 GHz Wi-Fi；加密网络输入密码，
   然后点击“连接此 Wi-Fi”。
5. NOTE4 会先验证网络和密码。失败时不会保存错误配置，也不会重启，可直接修改后重试。
6. 成功后，手机和墨水屏都会显示 NOTE4 获得的局域网 IP；设备随后自动重启。
7. 在“墨水屏提醒事项”Mac 应用中填写该地址并同步。

若需要更换 Wi-Fi，长按上键进入设置，在“Wi-Fi 与网络”中选择重新配置。旧配置会
保留到新网络验证成功，避免输入错误密码后设备失联。

## 按键

| 按键 | 操作 |
| --- | --- |
| 上键 | 选择上一项；第一项继续向上会回到最后一项 |
| 下键 | 选择下一项；最后一项继续向下会回到第一项 |
| OK 单击 | 确认当前事项完成 |
| 上键长按 | 进入设置；在子页面中返回上一级 |

按键切换默认采用局部刷新，以下情况改用全屏刷新：

- 画面变化范围较大。
- 已累计 8 次局部刷新。

Mac 按需上传当前选中画面和一张确认画面。OK 确认后，NOTE4 无需等待 Mac，
会立即把该事项以“圆圈内实心圆 + 标题删除线”显示在当前可见待办的下一行，
并把离线操作可靠保存到 NVS。

Mac 下次同步时把该事项写成 Apple Reminders 已完成状态，并在同一次同步刷新时移除完成项；
iCloud 随后同步到 iPhone/iPad。从 Mac/iPhone 完成的事项仍在下一次刷新时直接移除。

## 切换视图

长按上键进入设置，选择“切换视图”。上、下键在“今天、计划、全部、完成”四张卡片间
循环，OK 进入。视图选择保存在设备中，随后设备立即请求 Mac 按新视图重新读取 Apple
提醒事项。“今天”包含逾期、当天和无日期待办；“计划”包含所有有日期的未完成事项；
“全部”包含全部未完成事项；“完成”显示已完成事项且 OK 不会再次修改它们。

## 通信接口

NOTE4 使用 `/api/status`、`/api/snapshot`、`/api/display`、`/api/operations` 和
`/api/operations/ack`。Mac 端通过 `/api/status` 校验设备为 400 × 300 的 NOTE4 黑白版。

首次配网时，设备使用 AP+STA 模式保持 `192.168.4.1` 热点在线，
通过 DHCP 门户提示、通配 DNS 和 HTTP 跳转帮助 iPhone 自动打开中文页面。
`GET /api/wifi/scan` 提供去重并按信号强度排序的附近 Wi-Fi 列表。

NOTE4 画面为 400 × 300、每帧 15,000 字节，`1` 表示白色。

HTTP 接口没有公网身份验证，只应部署在可信局域网中。
