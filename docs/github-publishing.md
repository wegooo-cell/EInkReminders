# 第一次发布到 GitHub

## 1. 注册个人账号

1. 打开 <https://github.com/signup>。
2. 使用邮箱注册，或选择 Apple / Google 登录。
3. 选择一个用户名并完成验证。
4. 打开 GitHub 发来的邮件，完成邮箱验证。
5. 建议随后开启两步验证，保存好恢复代码。

GitHub 免费个人账号已经足够发布本项目。

## 2. 决定仓库可见性

- **Private（私有）**：只有你和受邀者能看到。适合先测试，也是本项目首次上传的稳妥选择。
- **Public（公开）**：任何人都能查看和下载。公开前应确认第三方源码、字体和图片的许可证，并为自己的代码选择许可证。

## 3. 交给 Codex 完成上传

注册并验证邮箱后，告诉 Codex：

- GitHub 用户名；
- 仓库使用“公开”还是“私有”；
- Git 提交中显示的名字和邮箱；
- 如果公开，是否已经确定开源许可证。

Codex 会在你的 Mac 上打开 GitHub 的设备授权页面。你只需登录并点击授权，不要把密码、验证码或访问令牌发给任何人。

完成授权后，Codex 会：

1. 创建名为 `EInkReminders` 的仓库，显示名称和说明使用“墨水屏提醒事项”；
2. 上传已整理的 v1.0.0 源码；
3. 创建 `v1.0.0` 标签和 GitHub Release；
4. 附上 NOTE4 固件、Mac App 安装包、校验文件和中文发布说明。
